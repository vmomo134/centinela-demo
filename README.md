# CENTINELA — demo pública

Demostración del sistema de monitoreo y alerta de incendios forestales en Guerrero
(detecciones térmicas de NASA FIRMS). Sitio estático con datos ya descargados; no es en vivo.

Abre la fecha con más actividad: `?fecha=2026-04-20`

Proyecto de Taller de Investigación II · Instituto Tecnológico de Acapulco.
Datos: NASA FIRMS (VIIRS y MODIS). Una detección satelital indica una fuente de calor
compatible con fuego; no confirma un incendio.
